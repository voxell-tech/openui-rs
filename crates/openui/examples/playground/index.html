openui-rs playground

OpenUI Lang 1.0, milestone 1. The Rust crate parses, streams, checks and evaluates everything on this page. No model, tool or network is called.

Limits

Bounds on the work untrusted model output can cause. Work past a bound is dropped and reported as limit-exceeded; the rest renders. Depth cannot go above the default here.
